## ✨ ما هو sc radio؟

تطبيق أندرويد يحوّل هاتفك إلى جهاز راديو حقيقي: تضغط **PTT** وتتكلم، فيسمعك كل من على نفس **القناة** في مداك. كل شيء يتم عبر **البلوتوث** مباشرة بين الهواتف، دون شبكة ودون خوادم.

يدعم حتى **10 أجهزة** على القناة الواحدة، حيث يعيد كل جهاز بث الصوت للآخرين، فيصلك صوت من هو أبعد من مدى البلوتوث المباشر.

## 🎛️ المميزات

| | الميزة |
|---|---|
| 📻 | راديو مرسوم بالكامل: شاشة LCD، أزرار، شبكة سماعة، وزر PTT كبير |
| 🔢 | قنوات من **1 إلى 99**، بالأزرار UP/DN أو بالكتابة بالضغط على شاشة LCD |
| 🔒 | وضع **PRIVATE**: قناة + كلمة سر، والصوت مشفّر بـ AES |
| 🔍 | **SCAN**: يبحث تلقائياً عن قناة فيها كلام |
| 👥 | عدّاد **Online Users** وقائمة المتصلين مع عدد القفزات |
| 📶 | مؤشر **قوة الاتصال**: مباشر أم عبر وسيط |
| 🎙️ | **تقوية الصوت وإزالة الضجيج** للميكروفون |
| 🎚️ | جودة **16 كيلوهرتز** عند الاتصال المباشر، و8 كيلوهرتز عبر الوسطاء |
| 🗣️ | **تغيير الصوت**: Normal / Hi Pitch / Low Pitch |
| ⭐ | **قنوات محفوظة** بأسماء تضعها أنت (ضغطة مطولة على M) |
| 💬 | **رسائل نصية** بشاشة كاملة |
| 🔔 | أصوات الراديو: تشغيل، روجر، نقرة تغيير القناة |
| 💡 | ضوء **LED**، ومؤشر مستوى الصوت، وتوهج واهتزاز عند الاستقبال |
| 🔐 | **زر قفل** يمنع الضغط الخاطئ في الجيب (يقفل كل شيء حتى PTT) |
| ⚙️ | شاشة **إعدادات** تفعّل أو تلغي كل ميزة |

## 🚀 كيف تستعمله

1. ثبّت التطبيق على كل الأجهزة وامنحه إذن **الميكروفون** و**البلوتوث**.
2. اضغط زر التشغيل الأزرق.
3. اربط الأجهزة بإحدى طريقتين:
   - **اقرنها مرة واحدة** من إعدادات بلوتوث أندرويد، وبعدها تتصل تلقائياً.
   - أو اضغط **M ← ربط أجهزة جديدة** على الجهازين في الوقت نفسه.
4. اختر نفس القناة على الجميع، واضغط **PTT** مع الاستمرار وتكلّم.

### التحكم السريع

| الإجراء | الطريقة |
|---|---|
| تغيير القناة | UP / DN |
| كتابة رقم القناة | اضغط على شاشة LCD |
| قائمة المتصلين | اضغط على `Online Users` |
| الوضع (قريب / خاص) | اضغط على شارة `NEARBY` |
| القائمة | اضغط **M** |
| حفظ القناة الحالية | ضغطة مطولة على **M** |
| الرسائل | الزر الأحمر **MSG** |
| قفل الشاشة | اضغط أيقونة القفل، وللفتح اضغط مطولاً |

## 🧠 كيف يعمل (باختصار)

- يتصل كل جهاز بعدة جيران عبر **Bluetooth Classic RFCOMM** ويكوّن شبكة شبكية (mesh).
- كل حزمة تحمل رقم القناة، ويعيد كل جهاز إرسالها مع منع التكرار، فيصل الصوت لمن هو أبعد.
- الصوت يُضغط بصيغة **µ-law** (8 أو 16 كيلوهرتز) ويُرسل على دفعات من 20 ملّي ثانية.
- الإرسال **نصف مزدوج** (واحد يتكلم في كل مرة)، كالراديو الحقيقي.

## 📏 حدود يجب معرفتها

- **المدى:** من 10 إلى 30 متراً لكل قفزة بين جهازين، والقفزات تزيد المدى.
- **عدد الأجهزة:** الحد الفعلي حتى 10 أجهزة، لكنه يتوقف على قدرة بلوتوث كل هاتف.
- **الوضع الخاص:** الصوت والرسائل مشفّرة، لكن الأجهزة الوسيطة تمرّر الحزم دون أن تفهمها.
- **أندرويد فقط:** يحتاج أندرويد 8.0 فأعلى.

## 🔐 الخصوصية

- لا إنترنت، لا حسابات، لا تتبع، لا إعلانات.
- كل البيانات (القنوات المحفوظة والإعدادات) تبقى على جهازك فقط.
- التطبيق يطلب الميكروفون فقط أثناء الإرسال، والبلوتوث لربط الأجهزة.
